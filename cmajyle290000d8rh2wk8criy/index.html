PSP视频格式PMF与MP4之间的直接转换

delphis
2025-05-12

最近帮忙处理一些PSP游戏汉化需要给PMF视频加字幕的问题，为了提高效率，弄了一个简化的PMF和MP4之间实现互相转换的工具PMFaerie。
标题里面写的“PMF与MP4之间的直接转换”其实不算严谨，应该是说使用层面上的直接转换，也就是说使用时只需要选择MP4文件，然后点击转换就行了，最后得到一个pmf，操作得到了很大的简化。
核心工具全是现成的，主要是依赖索尼的PSP开发SDK里面的PSMF Stream Composer Suite工具链，以及地球最强开源音视频处理工具FFMPEG。
PSF全称Playstation Media format(PS媒体格式)，主要用在PSP界面的游戏图标动画和游戏内部的视频，如果是做汉化工作，那么避不开这种格式。

PMFaerie的简单说明：

  1. MP4 → PMF 转换：将常见的视频文件（如 MP4）转换为 PSP兼容的 PMF 格式。
  2. PMF → MP4 转换：将 PMF 文件解复用并重新封装为通用的MP4格式，方便在现在的各种视频工具中编辑。

工具在执行转换过程中，会自动处理所有中间文件的生成和清理，用户无需关心复杂的命令行操作细节。

MP4转PMF

这个过程的步骤要比PMF到MP4多不少，在PSMF Stream Composer Suite工具链中，有好几个相关的处理工具，其中包括一个带界面的综合性工具UmdStreamComposer.exe，如果不熟悉命令行工具的话，可以用这个，具体可以参考中国宋庄大佬的文章：
不过工具包里面还包括了好几个命令行工具，这些工具完全可以作为组件拼装到其他程序里面调用，提升效率，而且开发包里面还附带了使用文档。

  2. 音频转换 WAV -> ATX （命令行工具psmfenc）

    把刚才的WAV转成需要的ATX格式，这里需要指定平均比特率，文档里面说明了，最大支持到320kbps。


    还有个很重要的参数-adjust_v，这是指定一个参考视频（就用刚刚输出的AVI视频），让最后输出的ATX和这个视频的长度一模一样，如不指定此参数，那可能后续会出现音画不同步，处理会报错，无法生成PMF。

  3. 视频转换 AVI -> BSF （命令行工具psmfenc）

    这一步的自定义参数只需要注意平均比特率，文档同样给出了范围，1000~2000之间。

  4. 复用 ATX+BSF -> MPS （命令行工具psmfmux）

    这步的命令很简单，只需要把上两步输出的atx音频流和bsf视频流输入，输出一个mps视频文件。

  5. MPS -> PMF (命令行工具PsmfComposerCMD)

    这步也是最后一步，很简单的命令，指定上一步的mps路径，以及最终输出的pmf路径。

GUI工具的实现

分成两个tab，一个MP42PMF，一个PMF2MP4，其实MP42PMF不仅是MP4可以转，常见的各种视频格式都行，因为是FFMPEG来处理第一步得到AVI+WAV，而FFMPEG能处理的格式太多了。
由于在生成PMF过程中有好几步，而且中间会产生很多中间文件，于是GUI会自动生成一个随机文件夹，用于存放中间文件，并在得到最终的PMF后，删除这些文件，不占空间。
