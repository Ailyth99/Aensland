初代XBOX游戏汉化的一些简要指南

delphis
2025-06-03

这是一个非常初级的指南，主要是说明一下XBOX游戏的镜像特征，以及常见的文件格式。但不包括对档案文件（比如AFS,XPR等）进行解包，以及压缩相关的内容。

XBOX光盘镜像

首先说下XB游戏的载体，虽然是光盘，能下载到的游戏文件也是扩展名为ISO的镜像文件，但这些ISO分成两种：

  • REDUMP项目制作的镜像：这种镜像一看大小都是4~6GB左右，解压后大约占满一张DVD9，这种属于原始镜像。
  • XISO（注意它的扩展名依然是ISO）：则根据游戏而变化，从几百MB到五六GB的都有。

像XEMU之类的模拟器，只支持加载XISO，如果你下载的是REDUMP的原始镜像ISO，还需要先转换成XISO。
可以使用这个在线的转换工具：https://xiso.antangelo.com/ （基于WASM运行在本地，无需实际上传镜像）

原始镜像为啥那么大呢？ 因为在游戏数据之外还保存了诸如演示视频之类的数据，可以当做普通DVD拿到其他设备播放，另外就是一些压缩不动的随机填充数据。
XBOX光盘里面有两个分区：

  • 一个是 游戏分区，文件系统是专门开发的XBOX DVD FILE SYSTEM，简称XDVDFS。
  • 另一个分区就是普通DVD那种 ISO9660文件系统。
    所以下载一个原始镜像，可以用WINDOWS10的虚拟光驱打开，但是只能看到一些视频文件，而找不到任何游戏数据相关的文件。
    XISO就是剥离了非游戏文件，只保存了XDVDFS分区的镜像文件。

如果想把XISO里面的数据抽取出来，需要使用 UltraISO(可以用，但是无法获取文件的时间戳)，或者 Xbox Image Browser，把所有抽取的数据保存在一个文件夹里面，然后汉化就是修改其中的一些文件。
修改完之后需要重建镜像，这时候可以用 Qwix 这个工具，最新版本是1.01。选择 create ISO，选择 local folder，再选择之前存放所有数据的文件夹，以及保存新ISO的位置即可。
这个过程生成的ISO就是XISO，可以在模拟器直接运行。

XBOX游戏的主启动文件为 default.xbe，xbe 即为 XBOX executable file（XBOX可执行文件），每个游戏镜像根目录都有一个。相当于PS1，PS2的那种 SLPS_***.**，是整个游戏运行的入口。

图像格式

除了各种像素格式的位图之外，XBOX游戏最常见的图像格式是各种DXT有损压缩图像，包括 DXT1, DXT3, DXT5。这类图像在PC游戏也很常见。具体可以参考这个WIKI：Texture formats overview
这些不同的DXT压缩图像数据被装在各种各样的图像容器里，比如常见的 DDS 格式, 使用XNView等PC上的查看器可以直接查看DDS。

关于像素重排 (Swizzling)

DXT压缩图像一般直接储存，XBOX开发之初应该就考虑到了GPU对这种格式的直接支持，所以通常无需重新处理这些图像数据。而那些原始的位图（如RGBA8888），则往往经过了像素重排（swizzle）以优化GPU显存读取效率。

这里使用的重排方法是 Morton Order (Z-order curve)，你可以调用 ReverseBox 这个Python库来完成，也可以参考其代码实现，做一些有针对性的转换小工具提升效率。

如果要修改图像的话，就导出为常见的PNG或者BMP，编辑后再进行重排，导入游戏。

RGBA8888 的位图在其他游戏里面也不少，比如《AIRFORCE DELTA 2》的机体贴图，同样的也是MORTON swizzle：


也有些位图没经过重排的，目前我接触过的有《铁甲飞龙1》，其扩展名为 .CGZ 的文件，实际是储存的原汁原味的 BGRX5551 图像。

视频格式

XBOX标准的视频格式为 XMV (Xbox Media Video)。微软的官方XBOX SDK (XDK) 里面包含有处理XMV的相关工具。

第三方视频格式在XBOX游戏中也比较常见：

  • **SFD (Sofdec)**：由CRI Middleware开发，主要在日系游戏中使用。
    • 工具提示：处理SFD可以去archive.org搜索criware泄露的工具，在2020年的一次卡普空泄露中，包括WII版的生化危机暗黑编年史的源代码，重要的不是这个，而是其中包含了一套从未泄露过的criware的某个版本的工具包（还有一些WII开发的工具包）…里面那个版本的SFD处理工具可以直接编码PS2,XBOX,NGC等平台要求的参数的SFD。
  • **BIK (Bink Video)**：由RAD Game Tools开发，欧美游戏用的较多。
    • 工具提示：处理BIK视频，可以直接搜索并使用RAD Game Tools官方提供的套件。

音频格式

XBOX官方SDK (XDK) 中推荐的音频格式是 XMA (Xbox Media Audio)。据称处理起来相对容易。

当然，也有游戏使用第三方音频格式，例如：

  • ADX：同样来自CRI Middleware，这类格式通常有较为成熟的第三方工具支持。
